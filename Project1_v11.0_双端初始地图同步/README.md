# 六边形网格寻路与可视化

这是一个使用SFML库实现的六边形网格寻路与可视化程序。程序生成一个大型六边形网格，随机选择起点和终点，然后使用随机深度优先搜索（DFS）算法找到一条从起点到终点的路径，并将其可视化显示。

## 项目结构

项目由以下文件组成：

1. **SingleHex.h/cpp**：基础六边形类和功能定义，包含坐标系统、网格单元状态和基础功能函数。
2. **PhysicalHexGrid.h/cpp**：物理网格类，负责生成网格结构、选择起点终点和寻找路径。
3. **VirtualHexGrid.h/cpp**：虚拟网格类，负责可视化显示和用户交互。
4. **HexScene.h/cpp**：场景管理类，负责不同场景的切换和管理。
5. **main.cpp**：主程序文件，程序入口点，使用场景管理器处理不同模式。

## 功能说明

- **场景管理**：支持单人模式和双人模式。
- **六边形坐标系统**：使用轴坐标系统(q,r)表示六边形网格中的位置。
- **网格生成**：生成一个由多个小六边形组成的大型六边形网格，网格半径由用户输入决定。
- **随机起点和终点**：在网格边界上随机选择起点和终点，尽量使它们位于相对的位置。
- **寻路算法**：使用随机深度优先搜索算法寻找从起点到终点的路径。
- **路径可视化**：使用SFML库将网格和寻找到的路径可视化显示。
- **双人模式**：支持玩家之间的交互，两个玩家相遇后可以显示相对路径。

## 编译和运行

### 依赖

- C++编译器（支持C++11或更高版本）
- SFML库（用于图形渲染）

### 编译命令

```bash
g++ -std=c++11 main.cpp SingleHex.cpp PhysicalHexGrid.cpp VirtualHexGrid.cpp HexScene.cpp -o hex_path -lsfml-graphics -lsfml-window -lsfml-system
```

### 运行

编译成功后，运行生成的可执行文件：

```bash
./hex_path
```

程序会显示菜单让你选择游戏模式，然后根据选择启动相应的场景。

## 使用说明

1. 运行程序后，从菜单中选择游戏模式（单人模式或双人模式）。
2. 输入网格半径（3-20之间）。
3. 程序会生成一个六边形网格，在边界上随机选择起点（绿色）和终点（红色）。
4. 单人模式直接显示寻找到的路径。
5. 双人模式允许两个玩家在网格中移动，当两个玩家相遇时，显示相对路径。
6. 关闭窗口可退出程序。

## 备注

- 如果输入的网格半径小于3，将自动设置为3；如果大于20，将自动设置为20。
- 程序会尝试选择距离较远的起点和终点，以使寻路更有挑战性。
- 使用随机DFS算法，可能不会找到最短路径，但能保证找到的路径不会回头。

## 参数说明
- `WINDOW_WIDTH`：窗口宽度
- `WINDOW_HEIGHT`：窗口高度
- `HEX_SIZE`：六边形大小
- `GRID_RADIUS`：网格半径（层数）

## 算法说明
### 深度优先搜索(DFS)算法
1. 从起点开始，标记当前节点为已访问
2. 如果当前节点是终点，则找到路径，返回true
3. 获取当前节点的所有邻居，并随机排序
4. 遍历所有邻居：
   - 如果邻居在网格内且未被访问，则记录路径并递归探索
   - 如果递归探索返回true，则找到路径，返回true
5. 如果所有邻居都探索完毕但没有找到路径，返回false
