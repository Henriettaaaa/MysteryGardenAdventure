# 六边形网格寻路游戏

这是一个基于六边形网格的寻路游戏，支持单人和多人模式。玩家可以在六边形网格中移动，从起点移动到终点。

## 功能介绍

1. **网格生成**：程序会生成一个大型六边形网格，由多个小六边形单元格组成。
2. **路径寻找**：程序会自动生成从起点到终点的一条随机路径。
3. **玩家互动**：玩家可以使用键盘控制角色在六边形网格中移动。
4. **多人模式**：支持两个玩家同时在线游戏，实时同步位置和游戏状态。

## 游戏模式

### 单人模式
1. 启动游戏后，选择"开始游戏"
2. 输入网格大小（3-20之间）
3. 阅读操作说明并按任意键继续
4. 游戏窗口打开，玩家（蓝色）从起点出发
5. 使用键盘移动到红色终点位置获胜

### 多人模式
1. 在一台电脑上启动服务器：
   ```
   mazeGame.exe server [port]
   ```
   如果不指定端口，默认使用54000端口

2. 在另一台电脑上启动客户端：
   ```
   mazeGame.exe client <serverIP> [port]
   ```
   需要指定服务器的IP地址，端口可选

3. 服务器端会生成迷宫并等待客户端连接
4. 客户端连接后，双方可以同时开始游戏
5. 两个玩家的位置会实时同步
6. 当任一玩家到达终点时，游戏结束并显示完成时间

## 控制方式

玩家可以使用以下键盘按键在六个方向上移动：
- **A键**：向左移动
- **D键**：向右移动
- **W键**：左上移动
- **X键**：右下移动
- **E键**：右上移动
- **Z键**：左下移动

## 游戏规则

- 玩家起始位置在绿色的起点
- 移动到红色的终点位置后获胜，控制台会打印"You win!"
- 移动不能超出六边形网格的边界，如果尝试移动到边界外，角色会保持在原位
- 游戏开始时将自动启动计时器，显示在游戏界面顶部
- 当玩家到达终点时，计时器停止，显示完成时间
- 在多人模式下，两个玩家的位置会实时同步，可以看到对方的移动

## 颜色说明

- **蓝色**：当前玩家位置
- **绿色**：其他玩家位置
- **红色**：终点
- **黄色**：自动生成的路径（用于参考）
- **灰色**：空白区域

## 技术实现

- 使用SFML图形库进行渲染
- 采用轴坐标系统(q,r)表示六边形网格
- 使用随机深度优先搜索(DFS)算法生成路径
- 玩家移动通过键盘事件处理实现
- 边界检测确保玩家不会移动到网格外部
- 使用TCP Socket实现网络通信
- 采用客户端-服务器架构实现多人游戏

## 网络通信

- 服务器负责生成迷宫并同步给客户端
- 使用TCP协议确保数据传输的可靠性
- 实现了以下消息类型：
  - INIT_GRID：初始化网格数据
  - PLAYER_MOVE：玩家位置更新
  - GAME_END：游戏结束时间同步
