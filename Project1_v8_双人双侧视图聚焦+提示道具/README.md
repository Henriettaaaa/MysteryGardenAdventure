# 虚拟迷宫游戏

## 项目简介

这是一个基于C++和SFML实现的虚拟迷宫游戏系统，融合了迷宫生成、路径规划和相对论可视化等功能。项目提供了友好的图形用户界面，支持多种游戏模式，并通过视觉化效果展示相对路径的概念。

## 系统要求

- Windows 10/11
- Visual Studio 2019/2022
- SFML 2.5.1 或更高版本
- C++17 标准
- 支持MP3格式的音频播放

## 核心功能

### 1. 主界面系统

- 游戏标题展示
- 三种游戏模式选择：教学模式、单人模式、双人模式
- 登录和排行榜功能入口
- 背景音乐控制
- 场景转换管理

### 2. 物理迷宫系统（PhysicalMaze）

- 支持自定义迷宫大小
- 使用并查集算法确保迷宫的连通性
- 随机生成墙壁，保证迷宫的随机性
- 采用权重优化的并查集实现
- BFS算法寻找最短路径

### 3. 虚拟迷宫系统（VirtualMaze）

- 将物理迷宫映射到虚拟空间
- 提供图形化界面展示
- 支持迷宫状态的实时更新
- 可视化展示路径和墙壁
- 路径上添加数字标记，显示路径顺序
- 支持玩家交互控制
- 实时显示玩家位置和移动轨迹
- 双人模式下支持物品功能和绝对路径显示
- 通过按钮系统切换物品和路径显示

### 4. 玩家交互系统

- 支持键盘方向键控制玩家移动
- 实时碰撞检测
- 起点和终点标记
- 玩家位置实时更新
- 移动轨迹可视化

### 5. 相对论路径展示

- 计算并展示绝对路径
- 生成相对路径A和B
- 通过不同颜色区分路径类型
- 交互式切换路径显示模式
- 在路径上显示序号标记，清晰展示路径顺序
- 支持通过按钮选择显示绝对路径

### 6. 用户系统（UserManager）

- 用户注册与登录功能
- 密码验证和数据加密
- 用户信息本地存储与管理
- 游戏成绩记录和更新
- 登录状态维护
- 图形化登录界面

### 7. 排行榜系统（Leaderboard）

- 按迷宫大小分类的排行榜
- 玩家成绩实时记录与排名
- 展示用户名和完成时间
- 按完成时间排序
- 美观的排行榜界面
- 返回主界面功能

## 游戏模式

### 1. 教学模式

- 提供游戏规则和操作指南
- 基础迷宫生成教学
- 相对论路径概念讲解
- 适合初次接触游戏的玩家

### 2. 单人模式

- 独自探索迷宫
- 计时挑战
- 迷宫大小可调节
- 难度递增
- 支持键盘控制移动
- 实时显示玩家位置
- 记录完成时间并更新排行榜

### 3. 双人模式

- 分为两个阶段：
  1. 初始阶段：两玩家在迷宫中寻找对方，直到相遇
  2. 相对路径挑战阶段：相遇后进入左右分屏模式，各自要走完绝对路径
- 左侧屏幕显示玩家A及A相对于B的相对路径
- 右侧屏幕显示玩家B及B相对于A的相对路径
- 哪位玩家先到达终点谁获胜
- 支持自定义迷宫大小
- 支持键盘控制移动（玩家A使用方向键，玩家B使用WASD）
- 实时显示玩家位置和移动轨迹
- 支持物品功能，可通过按钮选择使用
  - 玩家可获得延迟道具（Delay Item）
  - 点击相应的物品按钮使用道具
  - 使用后会延迟对方玩家移动3秒钟
  - 使用后按钮变灰表示已使用
  - 每局游戏每位玩家只能使用一次道具
- 支持绝对路径显示，帮助玩家理解相对路径概念
  - 通过绝对路径按钮可切换显示/隐藏绝对路径
  - 玩家A和玩家B分别有各自的绝对路径按钮
  - 按钮点击后状态会改变，表示当前是否显示绝对路径

## 技术实现

### 1. 用户界面

- 基于SFML实现的图形界面
- 交互式按钮系统
- 场景管理和状态切换
- 背景音乐控制
- 响应式按钮设计

### 2. 迷宫生成算法

- 初始化size × size大小的物理迷宫
- 使用并查集算法确保连通性
- 随机打乱墙的顺序保证随机性
- 通过权重优化提高合并效率

### 3. 路径查找算法

- 使用BFS算法寻找最短路径
- 支持从任意起点到终点的路径查找
- 记录完整路径信息

### 4. 虚拟映射系统

- 物理坐标到虚拟坐标的映射
- 处理墙壁和通路的转换
- 支持路径的虚拟展示
- 路径上的数字标记系统

### 5. 玩家交互系统

- 键盘事件处理
- 碰撞检测算法
- 位置更新和轨迹记录
- 实时渲染更新

### 6. 用户数据管理

- 基于文件的用户信息存储
- 用户身份验证
- 成绩记录和排序算法
- 用户信息加载和保存

### 7. 计时系统

- 精确计时功能
- 时间格式化显示
- 与用户系统集成记录最佳时间
- 支持物品延迟效果的计时

## 类设计

### 1. MainScene 类

主场景类，负责游戏主界面的显示和交互。

**主要功能：**

- 显示游戏标题和各种按钮
- 处理用户交互事件
- 管理背景音乐播放
- 控制场景状态转换
- 按钮状态管理和更新

### 2. Button 类

按钮类，用于创建可交互的界面元素。

**主要功能：**

- 设置按钮外观和文本
- 处理鼠标悬停和点击事件
- 支持自定义回调函数
- 按钮状态管理

### 3. PhysicalMaze 类

物理迷宫类，负责迷宫的底层生成和路径查找。

**主要功能：**

- 生成随机迷宫结构
- 使用并查集算法确保迷宫连通性
- 寻找从起点到终点的最短路径
- 提供物理迷宫的数据给虚拟迷宫使用

### 4. VirtualMaze 类

虚拟迷宫类，负责迷宫的图形化展示和交互。

**主要功能：**

- 将物理迷宫转换为可视化界面
- 显示绝对路径和相对路径
- 提供路径切换按钮
- 在路径上显示数字标记
- 处理玩家交互和移动
- 实时更新玩家位置和轨迹
- 单人模式计时功能
- 双人模式下物品按钮系统
  - 初始化物品按钮（initializeItemButtons方法）
  - 物品按钮点击检测（isItemButtonAClicked和isItemButtonBClicked方法）
  - 物品使用效果实现（延迟对方玩家移动）
  - 物品使用状态管理（playerAHasItem, playerBHasItem, playerAUsedItem, playerBUsedItem属性）
- 绝对路径显示按钮系统
  - 初始化绝对路径按钮
  - 按钮状态切换
  - 路径显示控制
- 优化的按钮交互处理逻辑

### 5. UserManager 类

用户管理类，负责用户数据的管理。

**主要功能：**

- 用户注册和登录验证
- 用户数据加载和保存
- 用户界面绘制和交互
- 最佳成绩记录和更新
- 提供登录状态和用户信息接口

### 6. Leaderboard 类

排行榜类，负责成绩排名的显示。

**主要功能：**

- 按迷宫大小获取排行数据
- 排行榜界面绘制
- 用户成绩排序和显示
- 交互式返回按钮

## 使用说明

### 游戏模式选择

- 在主界面选择需要的游戏模式：教学模式、单人模式或双人模式
- 单人模式：选择迷宫大小后开始游戏，使用方向键移动
- 双人模式：首先进入寻找对方阶段，之后进入相对路径挑战阶段

### 物品使用方法

1. 在双人模式下，每位玩家初始获得一个延迟道具
2. 点击屏幕上方的"Delay Item"按钮使用道具
3. 使用后，对方玩家将被延迟3秒钟
4. 每局游戏每位玩家只能使用一次道具

### 绝对路径显示

1. 在双人模式下，每位玩家可以通过点击"Absolute Path"按钮切换绝对路径显示
2. 显示绝对路径有助于理解相对路径的概念
3. 按钮状态变化表示当前是否显示绝对路径
