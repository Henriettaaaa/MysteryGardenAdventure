# 六边形网格寻路算法

## 项目简介
这是一个基于SFML图形库的六边形网格寻路算法演示程序。程序使用深度优先搜索(DFS)算法在六边形网格中找到从起点到终点的路径。

## 功能特点
- 使用六边形网格和轴坐标系表示地图
- 随机生成起点和终点
- 使用深度优先搜索(DFS)算法寻找路径
- 可视化显示寻路结果
- 支持随机化路径生成

## 技术实现
- 使用SFML图形库进行可视化
- 使用C++标准库实现数据结构
- 使用六边形轴坐标系(q,r)表示位置
- 使用深度优先搜索(DFS)算法进行寻路

## 使用方法
1. 确保已安装SFML库
2. 编译并运行程序
3. 程序会自动生成六边形网格，并随机选择起点和终点
4. 程序会使用DFS算法寻找从起点到终点的路径
5. 路径会以不同颜色显示在网格上：
   - 绿色：起点
   - 红色：终点
   - 黄色：路径

## 参数说明
- `WINDOW_WIDTH`：窗口宽度
- `WINDOW_HEIGHT`：窗口高度
- `HEX_SIZE`：六边形大小
- `GRID_RADIUS`：网格半径（层数）

## 算法说明
### 深度优先搜索(DFS)算法
1. 从起点开始，标记当前节点为已访问
2. 如果当前节点是终点，则找到路径，返回true
3. 获取当前节点的所有邻居，并随机排序
4. 遍历所有邻居：
   - 如果邻居在网格内且未被访问，则记录路径并递归探索
   - 如果递归探索返回true，则找到路径，返回true
5. 如果所有邻居都探索完毕但没有找到路径，返回false
