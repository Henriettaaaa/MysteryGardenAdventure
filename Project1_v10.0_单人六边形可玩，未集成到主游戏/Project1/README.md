# 六边形网格寻路游戏

这是一个基于六边形网格的寻路游戏，玩家可以在六边形网格中移动，从起点移动到终点。

## 功能介绍

1. **网格生成**：程序会生成一个大型六边形网格，由多个小六边形单元格组成。
2. **路径寻找**：程序会自动生成从起点到终点的一条随机路径。
3. **玩家互动**：玩家可以使用键盘控制角色在六边形网格中移动。

## 游戏流程

1. 启动游戏后，选择"开始游戏"
2. 输入网格大小（3-20之间）
3. 阅读操作说明并按任意键继续
4. 游戏窗口打开，玩家（蓝色）从起点出发
5. 使用键盘移动到红色终点位置获胜

## 控制方式

玩家可以使用以下键盘按键在六个方向上移动：
- **A键**：向左移动
- **D键**：向右移动
- **W键**：左上移动
- **X键**：右下移动
- **E键**：右上移动
- **Z键**：左下移动

## 游戏规则

- 玩家起始位置在绿色的起点
- 移动到红色的终点位置后获胜，控制台会打印"You win!"
- 移动不能超出六边形网格的边界，如果尝试移动到边界外，角色会保持在原位
- 游戏开始时将自动启动计时器，显示在游戏界面顶部
- 当玩家到达终点时，计时器停止，显示完成时间

## 颜色说明

- **蓝色**：玩家位置
- **绿色**：起点
- **红色**：终点
- **黄色**：自动生成的路径（用于参考）
- **灰色**：空白区域

## 技术实现

- 使用SFML图形库进行渲染
- 采用轴坐标系统(q,r)表示六边形网格
- 使用随机深度优先搜索(DFS)算法生成路径
- 玩家移动通过键盘事件处理实现
- 边界检测确保玩家不会移动到网格外部

## 实现思路

1. 使用轴坐标系统表示六边形网格中的位置
2. 定义六个方向的坐标偏移量，用于玩家移动
3. 每次移动前检查目标位置是否在网格内
4. 如果玩家到达终点，显示胜利信息
